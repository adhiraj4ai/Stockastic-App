# Saved Analyses (Chat Bookmarks) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users save a chat thread as a frozen, tagged "analysis" that the agent can autonomously recall (LLM-judged) to compare against a recurring series, plus a fast as-you-type hint and two browse surfaces.

**Architecture:** A new `SavedAnalysis` Django model in the `chat` app stores a frozen AI-generated summary + structured verdict + tags/tickers/series link to the originating `ChatSession`. A capture service summarizes a thread via a one-shot Claude Haiku call (Agent SDK, reusing existing OAuth auth) and captures any existing verdict card from the persisted message blocks. Two new user-scoped MCP tools (`search_saved_analyses`, `get_saved_analysis`) are added to `STOCKASTIC_MCP_SERVER` and granted to the five analysis subagents; a shared lexical matcher powers both a live `suggest` endpoint and prompt-time recall seeding injected into the orchestrator. The frontend gets a save-confirm modal, a "Saved" sidebar section, a `/bookmarks` catalog, and a composer hint chip.

**Tech Stack:** Django 5 + DRF, `claude_agent_sdk` (Agent SDK over OAuth token), Next.js (App Router) + TypeScript, Jest/RTL for frontend tests, pytest/Django `TestCase` for backend tests.

## Reference facts (verified against the codebase — do not re-derive)

- **MCP tool pattern** (`backend/chat/tools.py`): `@tool(name, description, {arg: type})` on `async def fn(args: dict) -> dict`; DB work wrapped in `@sync_to_async`; return `_result(prose, card={"type": ..., "data": ...}, _tool_name=name)`. Tools appended to the `ALL_TOOLS` list (ends ~line 3737) which feeds `STOCKASTIC_MCP_SERVER`. `tool_id(name)` → `"mcp__stockastic__<name>"`.
- **User scoping** (`backend/chat/_user_context.py`): call `get_user()` at the top of a tool to get the authenticated user (raises if unauthenticated). Set per-turn by `run_chat_session`.
- **Subagent grants** (`backend/chat/subagents.py`): each `AgentDefinition(tools=[tool_id("...") , ...])`. Five analysis agents: `MARKET_ANALYST`, `STOCK_ANALYST`, `BUY_SELL_STRATEGIST`, `PORTFOLIO_ADVISOR`, `BROKER_INTELLIGENCE`. (`PORTFOLIO_MANAGER` is excluded.)
- **Prompt assembly** (`backend/chat/agent.py`): `_format_prompt(user, message, memory)` renders `prompts/orchestrator.yaml`'s `user` template with `{date}/{username}/{memory}/{message}`. `run_chat_session` fetches `UserMemory` and calls `_format_prompt`. `_safe_prompt_value(value, max_len)` sanitizes. `_sdk_env()` returns the OAuth env for the SDK subprocess.
- **Verdict card shape** (persisted in `ChatMessage.blocks`): `{"kind": "card", "type": "ticker_verdict", "data": {...}, "tool": "get_ticker_verdict"}`. A simpler signal card is `{"kind":"card","type":"signal","data":{"symbol":..., "verdict":"BUY"|"SELL"|"HOLD", ...}}`. Assistant text is in `ChatMessage.text`; the full stream is in `ChatMessage.blocks`.
- **Models** (`backend/chat/models.py`): `ChatSession{id uuid, user FK, title, sdk_session_id, created_at, updated_at}`, `ChatMessage{session FK, role, text, blocks JSON, created_at}`. Notebook runs reuse `ChatSession` with title prefixed `"Notebook Session:"`.
- **Serializers/Views/URLs**: `backend/chat/serializers.py`, `backend/chat/views.py` (DRF `ModelViewSet`, `IsAuthenticated`, `get_queryset` filters by `request.user`, `@action` for custom routes), `backend/chat/urls.py` (DefaultRouter under `/api/chat/`).
- **Haiku model id**: `claude-haiku-4-5` (verified via claude-api reference; do **not** append a date suffix). class SavedAnalysis(models.Model):
    """A frozen, tagged snapshot of a chat analysis the agent can recall later."""

    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name="saved_analyses")
    # Link to the originating transcript; SET_NULL so deleting the chat keeps the snapshot.
    session = models.ForeignKey(
        ChatSession, on_delete=models.SET_NULL, null=True, blank=True,
        related_name="saved_analyses",
    )
    title = models.CharField(max_length=255)
    summary = models.TextField()                       # frozen synthesis (markdown)
    one_liner = models.CharField(max_length=280, blank=True, default="")
    category = models.CharField(max_length=64, blank=True, default="")
    tags = models.JSONField(default=list, blank=True)
    tickers = models.JSONField(default=list, blank=True)
    series_key = models.CharField(max_length=128, blank=True, default="", db_index=True)
    verdict = models.CharField(max_length=16, blank=True, default="")
    structured = models.JSONField(default=dict, blank=True)  # captured verdict/signal card data
    created_at = models.DateTimeField(auto_now_add=True, db_index=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        ordering = ["-created_at"]
        indexes = [models.Index(fields=["user", "series_key", "created_at"])]

    def __str__(self) -> str:
        return f"{self.user.username} · {self.title}"
```

"""Cheap lexical matcher over a user's SavedAnalysis records.

Shared by the live composer hint (suggest endpoint) and prompt-time recall
seeding. Ranking is keyword/ticker/tag overlap — no embeddings, no LLM.
"""
from __future__ import annotations

import re

from chat.models import SavedAnalysis

_WORD_RE = re.compile(r"[a-z0-9]+")
_TICKER_RE = re.compile(r"\b[A-Z]{3,7}\b")


def _tokens(text: str) -> set[str]:
    return set(_WORD_RE.findall((text or "").lower()))


def _score(query: str, sa: SavedAnalysis) -> int:
    q_tokens = _tokens(query)
    q_tickers = set(_TICKER_RE.findall(query or ""))
    score = 0
    # Ticker overlap is the strongest signal.
    score += 5 * len(q_tickers & {t.upper() for t in (sa.tickers or [])})
    # Tag overlap.
    score += 3 * len(q_tokens & {t.lower() for t in (sa.tags or [])})
    # Title / one-liner / category keyword overlap.
    haystack = _tokens(f"{sa.title} {sa.one_liner} {sa.category}")
    score += len(q_tokens & haystack)
    return score


def match_saved_analyses(user, query: str, limit: int = 5) -> list[SavedAnalysis]:
    """Return the user's saved analyses most relevant to `query`, best first.

    Returns [] for blank queries. Only records with a positive score are returned.
    """
    if not query or not query.strip():
        return []
    candidates = list(SavedAnalysis.objects.filter(user=user))
    scored = [(sa, _score(query, sa)) for sa in candidates]
    scored = [(sa, s) for sa, s in scored if s > 0]
    scored.sort(key=lambda pair: (pair[1], pair[0].created_at), reverse=True)
    return [sa for sa, _ in scored[:limit]]
```

```python
"""Build an editable SavedAnalysis draft from a chat session.

Captures any structured verdict/signal card from the persisted message blocks,
then summarizes the transcript with a one-shot Claude Haiku call. Falls back to
a naive draft if summarization fails, so saving never hard-fails.
"""
from __future__ import annotations

import asyncio
import json
import logging
import re

log = logging.getLogger(__name__)

_TICKER_RE = re.compile(r"\b[A-Z]{3,7}\b")
_VERDICT_CARD_TYPES = {"ticker_verdict", "signal"}
_MAX_TRANSCRIPT_CHARS = 12000

_SUMMARY_SYSTEM = (
    "You compress a financial-analysis chat thread into a compact, reusable record "
    "for a Nepal (NEPSE) stock investor. Return ONLY a JSON object — no prose, no code "
    "fences — with these keys:\n"
    '  "title": <=80 char headline,\n'
    '  "summary": markdown, <=350 words, with sections Key findings / Metrics / Verdict / Context,\n'
    '  "one_liner": <=160 char single sentence preview,\n'
    '  "category": short label, e.g. "Quarterly Fundamentals", "Technical Setup", "Portfolio Review",\n'
    '  "tags": 2-6 short lowercase tags,\n'
    '  "tickers": uppercase NEPSE symbols referenced (array).\n'
    "If the thread is not an analysis, still produce best-effort values."
)


def _transcript(session) -> str:
    parts: list[str] = []
    for msg in session.messages.all().order_by("created_at"):
        role = "User" if msg.role == "user" else "Assistant"
        if msg.text:
            parts.append(f"{role}: {msg.text}")
    text = "\n\n".join(parts)
    return text[:_MAX_TRANSCRIPT_CHARS]


def _capture_verdict(session) -> tuple[str, dict]:
    """Return (verdict_label, structured_data) from the latest verdict/signal card."""
    verdict, structured = "", {}
    for msg in session.messages.all().order_by("created_at"):
        for block in (msg.blocks or []):
            if block.get("kind") == "card" and block.get("type") in _VERDICT_CARD_TYPES:
                data = block.get("data") or {}
                structured = data
                verdict = str(data.get("verdict") or "")
    return verdict, structured


def _extract_tickers(text: str) -> list[str]:
    seen, out = set(), []
    for t in _TICKER_RE.findall(text or ""):
        if t not in seen:
            seen.add(t)
            out.append(t)
    return out


def _parse_json(text: str) -> dict | None:
    if not text:
        return None
    # Strip code fences / surrounding prose; grab the first {...} block.
    match = re.search(r"\{.*\}", text, re.DOTALL)
    if not match:
        return None
    try:
        data = json.loads(match.group(0))
        return data if isinstance(data, dict) else None
    except (ValueError, TypeError):
        return None


def _summarize_llm(transcript: str) -> dict | None:
    """One-shot Haiku summarization via the Agent SDK (reuses OAuth auth). None on failure."""
    if not transcript.strip():
        return None
    try:
        return asyncio.run(_summarize_async(transcript))
    except Exception:  # pylint: disable=broad-except
        log.exception("saved-analysis summarization failed")
        return None


async def _summarize_async(transcript: str) -> dict | None:
    from claude_agent_sdk import (
        AssistantMessage, ClaudeAgentOptions, ClaudeSDKClient, TextBlock,
    )
    from chat.agent import _sdk_env

    options = ClaudeAgentOptions(
        system_prompt=_SUMMARY_SYSTEM,
        model="claude-haiku-4-5",
        tools=[],
        allowed_tools=[],
        permission_mode="bypassPermissions",
        setting_sources=[],
        max_turns=1,
        env=_sdk_env(),
    )
    chunks: list[str] = []
    async with ClaudeSDKClient(options=options) as client:
        await client.query(transcript)
        async for message in client.receive_response():
            if isinstance(message, AssistantMessage):
                for block in message.content:
                    if isinstance(block, TextBlock):
                        chunks.append(block.text)
    return _parse_json("".join(chunks))


def _naive_draft(session) -> dict:
    first_user = session.messages.filter(role="user").order_by("created_at").first()
    last_assistant = session.messages.filter(role="assistant").order_by("-created_at").first()
    question = (first_user.text if first_user else "") or session.title
    answer = last_assistant.text if last_assistant else ""
    summary = f"**Question**\n\n{question}\n\n**Latest answer**\n\n{answer}".strip()
    return {
        "title": (session.title or question)[:80] or "Saved analysis",
        "summary": summary or "(no content)",
        "one_liner": (question or session.title)[:160],
        "category": "",
        "tags": [],
        "tickers": _extract_tickers(f"{question} {answer}"),
        "degraded": True,
    }


def build_draft(session) -> dict:
    """Build an editable draft dict for a SavedAnalysis from `session`.

    Keys: title, summary, one_liner, category, tags, tickers, series_key,
    verdict, structured, degraded.
    """
    verdict, structured = _capture_verdict(session)
    transcript = _transcript(session)
    llm = _summarize_llm(transcript)

    if llm:
        draft = {
            "title": str(llm.get("title") or session.title or "Saved analysis")[:255],
            "summary": str(llm.get("summary") or ""),
            "one_liner": str(llm.get("one_liner") or "")[:280],
            "category": str(llm.get("category") or "")[:64],
            "tags": [str(t)[:40] for t in (llm.get("tags") or []) if t][:8],
            "tickers": [str(t).upper()[:10] for t in (llm.get("tickers") or []) if t],
            "degraded": False,
        }
    else:
        draft = _naive_draft(session)

    # Merge tickers captured from the structured verdict (authoritative symbol).
    symbol = structured.get("symbol") if isinstance(structured, dict) else None
    if symbol and symbol not in draft["tickers"]:
        draft["tickers"].insert(0, str(symbol).upper())

    draft["verdict"] = verdict
    draft["structured"] = structured if isinstance(structured, dict) else {}

    # Derive a series key from the primary ticker + category (user-editable later).
    primary = draft["tickers"][0] if draft["tickers"] else ""
    cat = draft["category"]
    draft["series_key"] = f"{primary} · {cat}" if primary and cat else ""
    return draft
```

@tool(
    "search_saved_analyses",
    "Search the user's saved analyses (bookmarked past analyses). Returns a compact "
    "catalog — title, category, tags, tickers, series, date, one-line summary, verdict. "
    "Call this BEFORE a fundamental or technical analysis to check for a prior analysis "
    "or recurring series on this ticker/topic, then fetch the full one with "
    "get_saved_analysis to compare what changed. Args (all optional): ticker, category, "
    "tag, series_key, query, limit.",
    {"ticker": str, "category": str, "tag": str, "series_key": str, "query": str, "limit": int},
)
async def search_saved_analyses(args: dict) -> dict:
    user = get_user()

    @sync_to_async
    def _run():
        from .services.saved_match import match_saved_analyses
        ticker = (args.get("ticker") or "").upper().strip()
        category = (args.get("category") or "").strip()
        tag = (args.get("tag") or "").strip()
        series_key = (args.get("series_key") or "").strip()
        query = (args.get("query") or "").strip()
        limit = int(args.get("limit") or 20)

        qs = SavedAnalysis.objects.filter(user=user)
        if ticker:
            qs = qs.filter(tickers__contains=[ticker])
        if category:
            qs = qs.filter(category=category)
        if tag:
            qs = qs.filter(tags__contains=[tag])
        if series_key:
            qs = qs.filter(series_key=series_key)

        records = list(qs.order_by("-created_at")[:max(1, min(limit, 50))])
        # If a free-text query is given and structured filters didn't already
        # narrow things, rank by lexical relevance.
        if query and not (ticker or category or tag or series_key):
            records = match_saved_analyses(user, query, limit=max(1, min(limit, 50)))

        catalog = [{
            "id": str(r.id),
            "title": r.title,
            "category": r.category,
            "tags": r.tags,
            "tickers": r.tickers,
            "series_key": r.series_key,
            "verdict": r.verdict,
            "date": r.created_at.date().isoformat(),
            "one_liner": r.one_liner,
        } for r in records]

        if not catalog:
            return _result("No saved analyses match.", card=None, _tool_name="search_saved_analyses")

        lines = [
            f"- [{c['id']}] {c['title']} ({c['date']}) — {c['one_liner']} "
            f"[{', '.join(c['tickers'])}{' · ' + c['series_key'] if c['series_key'] else ''}]"
            for c in catalog
        ]
        prose = "Saved analyses (use get_saved_analysis with the id for full detail):\n" + "\n".join(lines)
        return _result(prose, card={"type": "saved_analyses", "data": {"items": catalog}},
                       _tool_name="search_saved_analyses")

    return await _run()


@tool(
    "get_saved_analysis",
    "Fetch one saved analysis in full by id: the frozen summary, captured verdict, and "
    "any earlier analyses in the same series (oldest→newest) so you can describe the trend. "
    "Args: id.",
    {"id": str},
)
async def get_saved_analysis(args: dict) -> dict:
    user = get_user()
    sa_id = (args.get("id") or "").strip()
    if not sa_id:
        return _result("id is required.", is_error=True, _tool_name="get_saved_analysis")

    @sync_to_async
    def _run():
        sa = SavedAnalysis.objects.filter(id=sa_id, user=user).first()
        if not sa:
            return _result("No saved analysis with that id.", is_error=True,
                           _tool_name="get_saved_analysis")

        series = []
        if sa.series_key:
            series = list(
                SavedAnalysis.objects.filter(user=user, series_key=sa.series_key)
                .order_by("created_at")
                .values("id", "title", "created_at", "verdict", "one_liner")
            )

        transcript_link = (
            f"/chat?session={sa.session_id}" if sa.session_id else "original chat deleted"
        )
        series_lines = "\n".join(
            f"  - {s['created_at'].date().isoformat()}: {s['title']} "
            f"({s['verdict'] or 'no verdict'}) — {s['one_liner']}"
            for s in series
        )
        prose_parts = [
            f"# {sa.title}",
            f"Saved {sa.created_at.date().isoformat()} · category: {sa.category or 'none'} · "
            f"tickers: {', '.join(sa.tickers) or 'none'} · verdict: {sa.verdict or 'none'}",
            f"Transcript: {transcript_link}",
            "",
            sa.summary,
        ]
        if series_lines:
            prose_parts += ["", f"Series '{sa.series_key}' (oldest→newest):", series_lines]
        prose = "\n".join(prose_parts)

        card = {
            "type": "saved_analysis",
            "data": {
                "id": str(sa.id),
                "title": sa.title,
                "summary": sa.summary,
                "category": sa.category,
                "tags": sa.tags,
                "tickers": sa.tickers,
                "series_key": sa.series_key,
                "verdict": sa.verdict,
                "structured": sa.structured,
                "date": sa.created_at.date().isoformat(),
                "transcript": transcript_link,
                "series": [
                    {"id": str(s["id"]), "title": s["title"],
                     "date": s["created_at"].date().isoformat(),
                     "verdict": s["verdict"], "one_liner": s["one_liner"]}
                    for s in series
                ],
            },
        }
        return _result(prose, card=card, _tool_name="get_saved_analysis")

    return await _run()

/** Loads an AI-suggested draft for the session, lets the user edit, then saves. */
export function SaveAnalysisModal({ sessionId, onClose, onSaved }: Props) {
    const [draft, setDraft] = useState<SavedAnalysisDraft | null>(null);
    const [tagsText, setTagsText] = useState('');
    const [loading, setLoading] = useState(true);
    const [saving, setSaving] = useState(false);
    const [error, setError] = useState('');

    useEffect(() => {
        let cancelled = false;
        savedApi
            .draft(sessionId)
            .then((d) => {
                if (cancelled) return;
                setDraft(d);
                setTagsText((d.tags || []).join(', '));
            })
            .catch(() => !cancelled && setError('Could not build a draft. Try again.'))
            .finally(() => !cancelled && setLoading(false));
        return () => {
            cancelled = true;
        };

        setError('');

            await savedApi.create({
                ...draft,
                tags: tagsText.split(',').map((t) => t.trim()).filter(Boolean),

```tsx
'use client';

import { useEffect, useRef, useState } from 'react';
import { savedApi } from '@/lib/api';
import type { SavedAnalysis } from './types';

interface Props {
    text: string;
    onAttach: (sa: SavedAnalysis) => void;
}

const MIN_CHARS = 8;
const DEBOUNCE_MS = 300;

/** As the user types, surface a related saved analysis. Click to attach it. */
export function SavedHintChip({ text, onAttach }: Props) {
    const [hint, setHint] = useState<SavedAnalysis | null>(null);
    const [dismissed, setDismissed] = useState('');
    const timer = useRef<ReturnType<typeof setTimeout> | null>(null);

    useEffect(() => {
        if (timer.current) clearTimeout(timer.current);
        if (text.trim().length < MIN_CHARS) {
            setHint(null);
            return;
        }
        timer.current = setTimeout(() => {
            savedApi
                .suggest(text)
                .then((rows) => setHint(rows[0] ?? null))
                .catch(() => setHint(null));
        }, DEBOUNCE_MS);
        return () => {
            if (timer.current) clearTimeout(timer.current);
        };
    }, [text]);

    if (!hint || hint.id === dismissed) return null;

    return (
        <div className="mb-1 flex items-center gap-2 rounded-md bg-emerald-900/30 px-2 py-1 text-xs text-emerald-200">
            <button className="flex-1 truncate text-left" onClick={() => onAttach(hint)} title={hint.one_liner}>
                📌 Related saved analysis: <span className="font-medium">{hint.title}</span>
            </button>
            <button className="text-emerald-400 hover:text-emerald-200" onClick={() => setDismissed(hint.id)}>
                ✕
            </button>
        </div>
    );
}
```
